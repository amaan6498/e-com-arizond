# 🛒 React E-Commerce Cart Application

This is a simple e-commerce cart project built with **React**, utilizing the **Context API** for global state management, and **React Router** for navigation. Products are fetched from the [Fake Store API](https://fakestoreapi.com/).

---

## 🚀 Setup Instructions

1. **Clone the Repository**

   ```bash
   git clone https://github.com/amaan6498/e-com-arizond.git
   cd my-app
   ```

2. **Install Dependencies**

   ```bash
   npm install
   ```

3. **Run the Application**

   ```bash
   npm start
   ```

4. **Open your Browser**
   ```bash
   http://localhost:3000
   ```

## 📌 Features

1. Fetches products from a public API

2. Add/remove items to/from cart

3. Adjust quantity (+/-)

4. Subtotal calculation

5. Sticky Mini Cart floating in the bottom-right corner

6. Cart page with item details and a checkout button
